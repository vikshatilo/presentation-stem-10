# Навчальний вебсайт: «Мета та структура презентації. Правила оформлення презентації»

Матеріал для учнів 10 класу профільного рівня, STEM-кластер пілотного академічного ліцею.

## Запуск
Відкрийте `index.html` у браузері. Сайт не потребує серверу, бібліотек чи встановлення.

## Публікація на GitHub Pages
1. Створіть репозиторій.
2. Завантажте `index.html` у корінь репозиторію.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

## Функції
- навчальні розділи про мету, аудиторію, структуру та дизайн презентації;
- покрокова дорожня карта з відстеженням прогресу (localStorage);
- інтерактивний планувальник слайдів;
- експорт плану у TXT;
- тест із автоматичною перевіркою;
- практичне STEM-завдання та критерії успіху;
- адаптивний дизайн для телефона, планшета й ПК.

Стиль натхненний наданим референсом: темний navy, неонові cyan/violet/pink акценти, світні панелі та футуристичний інтерфейс. Для фонового hero-зображення використано URL, наданий у запиті.
